# Caixa do Mês

Controle financeiro pessoal: lançamentos, gastos fixos automáticos, cartões e faturas, orçamento por categoria, metas, dívidas e dashboard.

Os dados ficam salvos **no navegador do aparelho** (nada é enviado para servidor). Use **Salvar backup** / **Carregar backup** para levar os dados para outro aparelho.
